Priprema za vježbu

Zadatke riješi u bilježnicu prije vježbe. U vježbi ćeš rješenja provjeriti logičkim pretvornikom.

  1. Primjenom zakona logičke algebre pojednostavi funkciju Y = AB + AB + AB.
  2. Primjenom zakona logičke algebre pojednostavi funkciju Y = A + AB + ABC.
  3. Za koliko je uređenih trojki (A, B, C) izraz AB + C istinit? a) 3   b) 4   c) 5   d) 6
  4. Samo NI vratima ostvari funkciju Y = AB + C. Prilagodi izraz i nacrtaj shemu sklopa.
  5. Samo NILI vratima ostvari funkciju Y = (A + B)·C. Prilagodi izraz i nacrtaj shemu sklopa.
  6. Što je minterm? Napiši minterm za kombinaciju ulaza A = 1, B = 0, C = 1. Kako se iz tablice stanja dobiva logički izraz metodom minterma?

Podsjetnik: zakoni logičke algebre

komutativnostA + B = B + AA·B = B·A
asocijativnost(A + B) + C = A + (B + C)(A·B)·C = A·(B·C)
distributivnostA + B·C = (A + B)·(A + C)A·(B + C) = A·B + A·C
idempotencijaA + A = AA·A = A
komplementA + A = 1A·A = 0
neutralni elementiA + 0 = A, A + 1 = 1A·1 = A, A·0 = 0
apsorpcijaA + A·B = AA·(A + B) = A

dvostruka negacijaA = A

Kako radi logički pretvornik

  • Sklop → tablica: iz sklopa spojenog na pretvornik određuje tablicu stanja.
  • Tablica → izraz: iz tablice stanja piše izraz metodom minterma.
  • Pojednostavi: iz tablice stanja izračuna najjednostavniji izraz (minimizacija).
  • Izraz → tablica: izraz iz polja Izraz 1 pretvara u tablicu stanja.
  • Izraz → sklop i Izraz → NI sklop: crtaju shemu izraza, odnosno shemu samo s NI vratima.
  • Negaciju upisuješ apostrofom (A' je A s crtom), množenje pišeš bez znaka, a zbrajanje znakom +. Primjer: AB'+C.

Zaključak

Zaključak napiši samostalno u bilježnicu, svojim riječima, u 8 do 12 rečenica. Neka sadrži:

  1. kako se iz zadane sheme dobiva tablica stanja i logički izraz, i čemu služi metoda minterma;
  2. što si postigao pojednostavljenjem izraza i kako se to vidi na shemi (broj vrata);
  3. kako si se uvjerio da zadani i minimizirani sklop daju isti izlaz;
  4. što si saznao o ulazima koji ne utječu na izlaz;
  5. kako se isti izraz može ostvariti samo NI vratima i zašto je to korisno u praksi;
  6. što treba učiniti s neiskorištenim ulazima vrata i zašto.
Simulacija je idealizirana: vrata nemaju kašnjenja ni granične razine napona. Logički pretvornik radi poput onog u programima za simulaciju sklopova, a negacija se u njemu piše apostrofom (A' je A s crtom).
